# verus/kani/pins.txt: the lines of the source that a Kani harness runs a
# copy of, because Kani cannot run the original (an inline `asm!` block),
# which `sh verus/seams.sh --check` requires to appear in each file in
# this order, each on the line after the one before (lines compared with
# leading and trailing whitespace removed; blank lines and `//` comment
# lines in the source skipped). A `...` line allows any lines in between.
# The original's lines come first, then the copy's, so a change to either
# fails the check until the copy, this list and the ledger status that
# cites the harness are revisited.
#
#   file<TAB>line[<TAB>NAME:ROLE]
#
# A third field ties a copy to its original: --check also requires the
# `NAME:orig` rows, in order, to equal the `NAME:copy` rows, and each
# side's rows (`orig` and `orig-only`, `copy` and `copy-only`) to be
# consecutive here. So the copy holds the original's lines but for the
# `-only` rows (the original's opening brace and asm! block, the copy's
# fn line).
#
