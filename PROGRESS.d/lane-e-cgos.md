## Design decisions

- Phase 2.5 task 14: the Makefile stays untouched on a bootc host; a `~/bin/docker` shim runs `sudo podman` and adds `--network=host` to `run` and `build` (netavark has no `nft` on the host, rootless podman has no `/run/containers/storage`), so every `make` target of the repository works unchanged and the cell exercises the same commands as the Docker cells. Reason: the smallest change with no merge surface in the Makefile; the host-network side effect (redis on the host's 6379) is harmless on a throwaway VM.
- Phase 2.5 task 14: `/var` is grown online with `resize2fs` from a `wolfi-base` container that sees the mount (`-v /var:/mnt/var`) instead of attaching a scratch disk. Reason: the image ships the 49 GiB partition already grown and only the filesystem small (OS-3363); two seconds, no reboot, no extra disk to delete.
- Phase 2.5 task 14: detached VM jobs on Chainguard OS run as `sudo systemd-run --uid=<login> ...` transient system units, not `setsid nohup`. Reason: the first image build died with the ssh session (the session scope is ended at logout on this image; `Linger=no`, so a `--user` unit would die too). The driver's cgos launch uses it; the Docker cells keep `setsid nohup`.
- Phase 2.5 task 14: the cgos cell writes `bench/results/scorecard-cgos-<arch>.md` (not `scorecard-c4a.md` / `scorecard-c4.md`, the same machine families): the per-CPU files record the Ubuntu 7.0 kernel with THP `madvise`, this one a 6.18 kernel with THP `always`, and a line for the same commit must not replace the other's.
- Phase 2.5 task 14: 3 rounds for the cgos four-way (the plan's table is 5) and the cells' scorecard: 5 rounds would have been about 35 minutes for the `ab` step alone per host and the shapes are 8 vCPU, so the file says 3 and the comparison with Ubuntu is by percentages and mechanism, never absolute.
- Phase 2.5 task 14: the four-way's container rows take the cell's protocol run (`make test-cgroup`) and the post-run repetition is quoted below them, so a reader sees both the passing protocol value and the stall frequency instead of one or the other.
