- Level 2 acceptance and the linker: q16's `.text` is 0x2020 bytes larger for a reason outside the compiler. Wolfi's GNU ld (binutils 2.47) has `--fix-cortex-a53-843419` on by default; the split changed the order of the heap functions in the single codegen unit (rustc emits local items in definition order, so the module boundaries and new mangled paths move them), and two `adrp`s (one in `Shared::alloc_huge`, one in `purge::Batch::flush`, whose source did not change) now sit at a page offset the erratum scan matches. Each gets a two-instruction veneer (`ldr` + `b` back) in a 4 KiB zero-filled stub section marked `$x`; q8's layout happened not to match. The instructions of every function are otherwise identical, which is what level 2 is meant to prove; the `.text=` equality test cannot hold across any change that moves code on this toolchain unless the workaround is off. Options: pass `-C link-arg=-Wl,--no-fix-cortex-a53-843419` (the reference hardware is Neoverse V2/N3 and Sapphire Rapids; a Cortex-A53 consumer would have to be named first), or make `codegen-diff.sh compare` ignore `$x` stub sections and compare functions by demangled, module-normalised name (its current fingerprint joins mangled names, so any module move shows as "changed"; and its `read -r n ex ma name` splits the instruction text at the first blanks, so the exact/masked hashes cover only the first token of each function). Neither is this lane's file.
