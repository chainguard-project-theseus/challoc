- Rule learnt for anyone adding a function-pointer table over the allocator: do not pass `&Shared` through the pointer. `super::shared()` is a constant address after the ready check and LLVM specialises every callee on it; a pointer-called function's parameters are opaque, so one such caller costs `heap_for_thread`, `stats::snapshot`, `Config::get`, `arena::free` and their callers the constant (seen as changed functions outside the edited file in the compare). Fetch the static inside the called function instead.
